❓ Частые вопросы

Что есть на сайте?

Планы-конспекты уроков, опорные конспекты для раздачи классу, видеоуроки и тесты для контроля знаний — по истории Беларуси в контексте всемирной истории для 11 класса.

Нужно ли регистрироваться?

Нет. Регистрация не требуется — все материалы для учителей доступны сразу.

Как идти по шагам?

Строго по очереди: выберите предмет → 11 класс → параграф → один из 4 форматов: видеоурок, подробный план-конспект, краткий конспект или тест. Вернуться назад можно кнопкой «Назад» или хлебными крошками сверху — начинать сначала не нужно.

Как использовать материалы на уроке?

Откройте план-конспект для объяснения темы, покажите видеоурок на экране, раздайте краткий конспект классу, а тест используйте для контроля знаний учащихся.
